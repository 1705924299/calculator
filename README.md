# 计算器项目

一个功能完整的网页计算器，支持基本运算和高级函数。

## 功能特性

### 基本运算
- 加法 (+)
- 减法 (-)
- 乘法 (×)
- 除法 (÷)

### 高级函数
- 倒数 (1/x)
- 平方 (x²)
- 平方根 (√x)
- 百分比 (%)

### 其他功能
- 表达式显示
- 连续等号运算
- 错误处理
- 显示长度限制（最多8位）

## 文件结构

```
calculater/
├── Untitled-1.html    # 主HTML文件
├── script.js          # 主要JavaScript逻辑
├── operations.js      # 操作配置和工具函数
├── style.css          # 样式文件
└── README.md          # 项目说明
```

## 模块化设计

### operations.js
包含所有计算操作的配置和工具函数：

- `operations` - 操作配置对象，包含每个函数的计算逻辑、表达式格式和错误检查
- `getOperatorSymbol` - 获取操作符显示符号
- `calculate` - 基本四则运算
- `formatResult` - 结果格式化（限制显示长度）

### script.js
主要的事件处理和状态管理：

- 事件监听器
- 状态管理（使用dataset）
- 用户界面更新
- 调用operations.js中的函数

## 使用方法

1. 在浏览器中打开 `Untitled-1.html`
2. 点击数字和操作符进行计算
3. 使用高级函数按钮进行特殊运算
4. 按等号查看结果

## 技术特点

- **模块化设计** - 操作配置与主逻辑分离
- **可扩展性** - 添加新函数只需在operations.js中配置
- **错误处理** - 完善的错误检查和显示
- **状态管理** - 使用HTML5 dataset进行状态存储
- **响应式设计** - 适配不同屏幕尺寸
